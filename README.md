# Shamoitree Pal — Personal Academic Website

This is a beginner-friendly personal academic and research portfolio made with plain HTML and CSS. It can be hosted free with GitHub Pages.

## Files
- `index.html` — the complete website.
- `README.md` — these instructions.

## Publish it on GitHub Pages

1. Sign in at https://github.com/
2. Create a **new public repository** named exactly `shamoitreepal.github.io` (if your GitHub username is different, use `YOURUSERNAME.github.io` instead).
3. In the new repository, choose **Add file → Upload files**.
4. Upload `index.html` from this folder. You can also upload your CV as `cv.pdf` once you are ready.
5. Click **Commit changes**.
6. Open the repository's **Settings** tab.
7. In the left sidebar, choose **Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Set branch to `main` and folder to `/ (root)`, then click **Save**.
10. Wait a few minutes, then open `https://shamoitreepal.github.io`. The first publication may take up to 10 minutes.

Official instructions: https://docs.github.com/en/pages/quickstart

## Personalize before sharing

Open `index.html` on GitHub and click the pencil icon to edit it.

- Replace `YOUR.EMAIL@example.com` with your professional email.
- Change the LinkedIn link to your real LinkedIn profile URL.
- Add your CV: upload a PDF named `cv.pdf`, then find the commented-out CV link in the hero section and remove the HTML comment markers around that link.
- Check all academic dates, awards, skills, and project descriptions for accuracy.
- For each project, replace placeholder or general links with the exact public repository, report, or paper. Do not publish confidential data or restricted research files.
- Keep only projects and claims you are comfortable discussing publicly.

After editing, click **Commit changes**. GitHub Pages will republish the site automatically.

## Important privacy note

A GitHub Pages website is public. Do not include phone numbers, private addresses, student IDs, confidential research data, passwords, API keys, or private documents.
