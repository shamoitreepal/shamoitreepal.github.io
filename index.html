Network economics · Machine learning

Predicting Diffusion Centrality Without Network Data

Replication and machine-learning extension inspired by research on information diffusion, using household and village data from Karnataka.

Methods: Lasso, Ridge, Random Forest, Gradient Boosting, grouped cross-validation.

GitHub profile / related work →

Financial econometrics

Modelling Financial Market Volatility

A time-series workflow examining volatility in market and macro-financial indicators, including NIFTY, USD/INR, Brent crude, CPI, and the repo rate.

Methods: ARCH-LM tests, GARCH, GJR-GARCH, EGARCH.
NLP · Monetary policy

Analysing RBI Monetary Policy Communications

An NLP pipeline to study monetary-policy communication using text preprocessing, TF-IDF, sentence embeddings, and classification approaches.

Focus: text analysis, policy communication, index construction and validation.
